# CoralBleachingProject
A project to develop a website from scratch that tells us information about coral bleaching at Kavarati Islands(Lakshwadeep). 

## Recovery handoff

Start with [RECOVERY_HANDOFF.md](docs/RECOVERY_HANDOFF.md) for the original assets,
Drive locations, known validation issues, and the staged reconstruction plan.

## Recovered comparison

The [external benchmark and Kavaratti report](docs/EXTERNAL_BENCHMARK_AND_KAVARATTI.md)
records the dataset audit, held-out image-level scores, six-video estimates,
limitations, and reproducible commands. The [local dashboard](coral-bleaching-ui/README.md)
shows those real outputs and can analyze a new upload with both methods.

The original notebook, source videos, and provisional review masks are
preserved. Downloaded datasets, model weights, frames, and other large outputs
are stored under ignored `generated/` paths.
